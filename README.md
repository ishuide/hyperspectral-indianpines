# hyperspectral-indianpines
Hyperspectral image classification on Indian Pines using LS denoising + ADMM sparse representation

The project focuses on hyperspectral image classification using the Indian Pines dataset, with an emphasis on improving performance through least square denoising and sparse representation. Hyperspectral imaging provides detailed spectral information across hundreds of bands, but the raw data often contains noisy or redundant bands due to sensor limitations and atmospheric interference. To address this, the dataset was first examined to identify bands with very low mean values or negligible variance, as these are considered dead bands and contribute little useful information. Additionally, water absorption bands commonly affected by atmospheric interference were removed, ensuring that only the most reliable and discriminative bands were retained for further processing.


Once the dataset was cleaned, it was normalized to ensure values were within a consistent range, allowing fair comparison between spectra. The data was reshaped from a three-dimensional cube into a two-dimensional structure of pixels and bands, enabling easier manipulation for analysis. Least square denoising was then applied to the spectral data, which effectively reduced noise while preserving the essential spectral shape of each pixel. This step ensured that small variations introduced by noise did not distort the spectral characteristics required for accurate classification. The denoising performance was validated by calculating error measures such as root mean squared error and spectral angle, confirming that the spectra were preserved with minimal distortion.


Following preprocessing and denoising, the dataset was split into training and testing portions, with 20% of the samples from each class used for training and the remaining 80% reserved for testing. This class-wise splitting ensured that all classes were fairly represented in both sets, avoiding class imbalance. Training samples were used to construct a dictionary of spectral signatures, while the test set provided the unknown samples to be classified. Before classification, both training and test spectra were normalized to eliminate the effect of brightness variations and focus solely on the spectral shape, which is more relevant for material identification.


The classification framework employed sparse coding using the Alternating Direction Method of Multipliers (ADMM). For each test spectrum, sparse coefficients were computed with respect to the training dictionary, ensuring that the test pixel was represented as a sparse combination of training atoms. The ADMM procedure involved iterative updates that gradually refined the sparse solution while enforcing sparsity and consistency with the observed data. This process yielded strongly sparse coefficients, meaning that only a few dictionary elements were active for each test pixel, highlighting the most relevant training samples contributing to its representation.


Finally, classification was performed using a residue-based decision rule. Each class in the dictionary was used to reconstruct the test pixel using only its corresponding coefficients, and the reconstruction error or residual was computed. The class that produced the lowest residual was assigned as the predicted label. This approach ensured that the classification decision was based on how well each class could represent the test spectrum, making it robust against noise and irrelevant features.


Overall, the project demonstrated that combining least square denoising with ADMM-based sparse representation significantly improves hyperspectral classification. The preprocessing ensured clean and reliable spectral data, while sparse coding emphasized class-specific discriminative information. The results confirmed that this pipeline is effective for handling complex hyperspectral datasets like Indian Pines, yielding accurate and robust classification performance.
